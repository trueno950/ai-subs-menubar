# Product

## Register

product

## Users

A Mac user managing personal subscriptions to AI services and checking their renewals and provider usage while working. The menu bar should make the important state visible at a glance without requiring a dashboard workflow.

## Product Purpose

AI Subs tracks recurring AI plan prices and renewal dates alongside live API spend or plan quota where providers expose usable endpoints. Success means the user can quickly tell what is connected, what is due, how much API usage has accumulated, and whether a quota is nearing its limit.

## Brand Personality

Technical, compact, and clear. The interface should feel native to macOS, practical rather than decorative, and calm until an actionable warning is needed.

## Anti-references

- False or alarm-colored warnings when a provider is merely not configured.
- Oversized dashboards or repeated cards that make a compact menu-bar utility feel dense and slow to scan.
- Status communicated by color alone.

## Design Principles

- **Label what each number means.** Keep recurring plan prices, month-to-date API spend, and provider-cycle quotas distinct.
- **Make the glance actionable.** Pair a status with its value and the next useful action.
- **Warn only when action is needed.** Missing setup is neutral; actual failures and quota thresholds are explicit.
- **Stay compact and native.** Prefer familiar macOS controls and concise rows over decorative containers.
- **Respect system readability.** Preserve legibility with larger text and stronger contrast; never rely on color alone.

## Accessibility & Inclusion

Support larger text and strong contrast. Pair semantic colors with text or icons, use native controls and system appearance behavior, and do not require motion to understand state.
